# Agent Runtime 独立审查

日期：2026-10-25。固定基线 04a29d2，初次审查实现提交 658caae。两位独立审查者分别检查 Standards 和 Spec。私有规格与设计仅从本地读取，未添加或发布。

## Standards

初次发现 3 项，最高 P1：

1. P1：审批请求没有预期 Revision，可能把旧挑战的决定应用到工具更新后的新暂停。Decide 现要求观察到的 Revision，过时返回 ErrConflict。
2. P2：工具升级后 Describe 返回无效 JSON 时，在验证前复制可能触发内部 panic。现统一验证元数据后复制，Describe panic 也转为错误。
3. P2：JSON 解码会把无效 UTF-8 静默替换。现读取前拒绝非法字节，保存和复制前验证源数据，避免身份或参数被规范化后继续执行。

复核通过：相关审批、工具说明、存储损坏、正常循环及取消回归连续三次执行通过，无剩余行动项。审查者未自行执行 race。

## Spec

初次发现 2 项，最高 P1：

1. P1：审批缺少观察版本，与 Standards 第一项重合。已通过 expectedRevision 修复。
2. P1：语义检查点校验允许重复工具调用身份，公开 API 复现中相同 ID 被执行两次。现验证历史 ID 唯一性、待执行计划与最近模型计划一致、结果对应关系及模型计数。恢复无效记录时拒绝执行。

修复复核另指出 Calls 为空时跳过计划长度比较；已改为无条件校验，增加“整份计划丢失但历史结果存在”的回归。

复核通过：重复执行复现现被拒绝，工具执行次数为 0；审批、语义损坏和真实进程恢复测试通过。没有扩大至供应商 API、Focus 或 Forest Core。

两轴最终均无剩余行动项。完整测试和 race 结果见 validation.md。
